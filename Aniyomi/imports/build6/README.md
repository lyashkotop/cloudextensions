## Нерешённые ограничения

MissAV: обе вкладки отвечают Cloudflare HTTP 403 в этой сети. Дополнительно проверены домены .ai и .ws — тоже 403. В приложении используется cookie-aware Cloudflare-клиент Aniyomi, но прохождение проверки на устройстве здесь не подтверждено.

Xnxx: популярное и пагинация работают; рабочий адрес общей ленты новинок пока не найден. Проверенные /new/, /newest и RSS возвращают 404, пустой/универсальный поиск не дал общей ленты. Эта неподдерживаемая вкладка остаётся отключённой; вместо неё не подставляются другие подборки.

## Исправления

Явные маршруты для каждого источника находятся в profiles.json → browse. Устранены ошибочный выбор «Recent Favorites» для новинок HeavyR, главная вместо новинок DarknessPorn/PunishWorld, смешивание watched/new у PornVideos и соседних блоков KVS. У Noodle/UKDevilz используются опубликованные range=month/range=recent с прежними RU/EN cookie.

Для SickJunk популярность означает нативный порядок WordPress по числу комментариев, для PornVideos — опубликованный блок текущих просмотров. Это не сортировка всего каталога по общему числу просмотров.

ForcedCinema: HTML-страница новинок включала записи следующей страницы, затем повторяла их при перелистывании. Публичный WordPress API с orderby=date и X-WP-TotalPages дал корректные страницы по 20 записей; изображения берутся из опубликованных данных вложений.

Strip2: минутная метка _refresh иногда давала пустой HTTP 200; исправлена на Unix-время в секундах, без дублирования параметра. Ленты с корректной меткой проверены заново.

Активные параметры сортировки сохраняются на следующих страницах. Ошибки/отмена сбрасывают состояние под mutex, чтобы не кэшировать неудачу и не ломать ожидающий запрос вкладки. Проверены фоновый прогрев, отсутствие ожидания соседней вкладки, общий запрос при одновременном открытии, повтор после HTTP 503 и отмены.
