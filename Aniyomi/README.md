# Cloud Extensions для Aniyomi

Один APK, 32 активных источника: 9 русских, 2 японских, 21 английский. `Unused` не включён. Это расширение для установленного Aniyomi, не отдельный видеоплеер. Android 8+; API расширений 14, поддерживаемый текущим Aniyomi.

Установи `CloudExtensions.apk`, открой **Aniyomi → Обзор → Расширения** и подтверди доверие расширению. В настройках Aniyomi должно быть разрешено отображение взрослых источников. Сайты сгруппированы префиксами `1.`, `2.`, `3.`.

## Возможности

- Стандартные вкладки «Популярное», «Новинки» и панель фильтров Aniyomi.
- Текстовый запрос, категория, выбранные/вручную исключённые теги и сортировка применяются совместно. Сочетание тегов «И»/«ИЛИ»; выбор диапазонов длительности (до 5, 5–10, 10–20, 20–40 и больше 40 минут; все включены изначально).
- Настоящие опубликованные каталоги тегов/категорий, в одном списке для выбора. При наличии опубликованных счётчиков — по числу видео, иначе без выдуманного рейтинга. Метки, полученные из карточек, дополняют список при повторном создании фильтров (кнопка сброса в текущей сессии). Популярные поисковые фразы не выдаются за теги. Где общего каталога нет, можно вводить точные метки вручную.
- Только обнаруженные у сайта варианты сортировки. Если сервер не умеет сортировать поиск по длительности, фиктивная глобальная сортировка не показывается; выбранные диапазоны длительности работают по метаданным.
- Сайт сохраняет свой порядок выдачи. Категория/несколько тегов/длительность дополнительно проверяются по метаданным; источник без серверного комбинированного поиска может отвечать медленнее.
- RU↔EN для запросов из 1–2 слов, оригинал первым, без дублей. Noodle Magazine и UKDevilz исключены; у них русская и английская cookie соответственно. Кэш названий разделён по источникам.
- Выдача возвращается без предварительного открытия страниц видео. Приватные карточки ThisVid исключены; пустой поиск не заменяется трендами. Автоматические стоп-слова полностью удалены; ограничения применяются только при явном выборе пользователя.
- Истинные названия, опубликованные описания и метки. Нет описания — поле пустое. Максимальное заявленное разрешение 1080p; HLS-варианты, подписанные ссылки, Referer/UA, источник-специфичные API и WebView для динамических плееров.

## Проверка и ограничения

Для текущих вкладок см. [аудит сборки 6](imports/build6/README.md); первичная проверка воспроизведения — [результаты](imports/validation.json). Проверены реальные HTTP-запросы нового Kotlin-кода, метаданные, заголовки изображений и доступные потоки без просмотра медиа. Проверены APK/DEX/манифест/подпись и контракты фильтров. Актуальный `AnimeExtensionLoader` Aniyomi явно поддерживает API 14; архитектура сверена с официальными и adult-репозиториями.

Запуск интерфейса APK на физическом Android/эмуляторе здесь не выполнен. WebView-путь проверен компиляцией, не устройством. MissAV в этой сети возвращает Cloudflare 403. У CDN некоторых сайтов остаются проверки Cloudflare/сетевые ограничения, а отдельные записи удалены. Это не считается успешным воспроизведением. У PornVideos популярное показывает опубликованный блок текущих просмотров, у SickJunk — нативную сортировку по числу комментариев. Рабочий адрес общей ленты новинок Xnxx пока не найден; эта вкладка отключена.

Aniyomi управляет собственным интерфейсом: расширение использует его вкладки и окно фильтров, а не добавляет произвольные новые экраны.

## Пересборка одной командой

Нужны Python 3.10+ и Java 21. Из корня репозитория:

```sh
python common/tools/fetch_tools.py --directory .aniyomi-tools/compiler
python Aniyomi/scripts/fetch_tools.py --directory .aniyomi-tools/android
export ANIYOMI_KEYSTORE=/path/to/aniyomi-release.jks
read -rs ANIYOMI_KEYSTORE_PASSWORD
export ANIYOMI_KEYSTORE_PASSWORD
python Aniyomi/scripts/build.py --tools .aniyomi-tools/android --compiler-tools .aniyomi-tools/compiler --version 6
python Aniyomi/scripts/check.py --tools .aniyomi-tools/android --compiler-tools .aniyomi-tools/compiler
```

Результат: `Aniyomi/build/CloudExtensions.apk`. Для обновления поверх установленного APK нужен **тот же ключ подписи** и больший `--version`. Не загружай ключ/пароль в публичный репозиторий.

GitHub Actions выполняет сборку и проверки при изменении `Aniyomi/`. Для подписанного APK добавь секреты `ANIYOMI_KEYSTORE` (Base64 содержимого JKS) и `ANIYOMI_KEYSTORE_PASSWORD`. Без них Actions создаёт явно обозначенный неподписанный артефакт для проверки, а не установочный релиз. Подключённая интеграция GitHub не разрешила управление секретами (HTTP 403); локальный APK подписан сохранённым приватным ключом.

## Структура и обновление

- `src/main/kotlin/.../cloudbundle`: фабрика, адаптер Aniyomi, фильтры, движок поиска, API отдельных сайтов и плееры.
- `src/main/kotlin/com/cloudextensions/russian`: перенесённые независимые парсеры и политики; CloudStream SDK не требуется и не включается в APK.
- `catalogs/profiles.json`: адреса, селекторы и особенности каждого активного сайта.
- `catalogs/<Site>.json`: реальные каталоги и элементы управления; диагностические сведения не включаются в исполняемый реестр.
- `scripts/generate_registry.py`: сжатый реестр; большие словари распаковываются при открытии фильтров конкретного сайта, а не всех сайтов при запуске.
- `scripts/discover_catalogs.py`, `enrich_controls.py`: обновление опубликованных каталогов/контролов. Для этих двух скриптов нужны `requests` и `beautifulsoup4`.
- `tests/`: проверки фильтров/кэша/пустого поиска и технический аудит настоящих сайтов.

Изменения CloudStream-кода сами по себе не меняют эту адаптацию. Правь нужный профиль или адаптер в `Aniyomi/`; для повторного импорта базовых селекторов есть `scripts/migrate_profiles.py` (перезаписывает profiles.json). Лицензии и происхождение: [NOTICE](NOTICE.md), [архитектура](imports/architecture.json).

Сборка 3: удалены автоматические стоп-слова и проверки первых семи карточек; запросы языковых веток параллельны, повторная выдача кэшируется на 60 секунд. Одиночный тег/категория с опубликованной ссылкой открывает соответствующий раздел без проверки меток каждого видео. Комбинированные фильтры могут требовать дополнительной загрузки метаданных.

Изменения исходников для сборки 4: кодирование адресов с пробелами/кириллицей; один общий список тегов с включением/исключением и сохранёнными ручными полями; единые понятные категории как фильтры по реальным меткам сайта. Списки категорий больше не разбирают десятки тысяч URI на потоке построения фильтров. Обычная выдача остаётся без предварительных запросов карточек. Проверена комбинация «БДСМ + до 5 минут + мейлдом − гей». Сортировки отображают только найденные возможности сайта.

Сборка 5: «Все теги» стоит первым, ручные поля сохранены. В категориях только опубликованные пункты сайта; удалены общие придуманные группы, Show more и фотоальбомы. Дополнены реальные каталоги Semyana/Vpoisk/BDSMStreak/EPorner. KVS-пагинация сохраняет запрос и сортировку, пересечение языковых веток не обрывает курсоры; дубли по числовому ID исключаются даже при другом slug. ThisVid добирает публичные ролики с нескольких страниц (с ограничением числа запросов), приватные остаются скрыты. Исправлены реальные маршруты популярных разделов. Rx-запросы отменяются при уходе с экрана; каталоги ограничены 20 секундами, очередь метаданных включена в четырёхсекундный бюджет. См. [реальный аудит](imports/build5/README.md); ограничения отдельных сайтов сохранены в отчёте.

Сборка 6: обе вкладки используют явные адреса в `catalogs/profiles.json → browse` для каждого источника; открывать главную ради угадывания маршрута больше не нужно. После первой загруженной вкладки соседняя прогревается одним фоновым запросом. Повторное открытие использует кэш 60 секунд. Ошибки и отменённые запросы сбрасывают состояние под mutex и допускают повторную попытку.

Исправлены реальные новинки DarknessPorn/PunishWorld/HeavyR, разделение блоков PornVideos, популярное SickJunk по комментариям, недавние/месячные выдачи Noodle/UKDevilz и точные ленты остальных источников. KVS-карточки берутся из основной ленты с пагинацией, без смешивания с соседними блоками. Фильтры сортировки сохраняются в адресах следующих страниц. ForcedCinema использует публичный API публикаций для новинок: HTML-пагинация сайта возвращала повторы. У Strip2 исправлен параметр обновления страницы, который мог возвращать пустой HTTP 200.

[Аудит обеих вкладок и времени ответа для всех источников](imports/build6/README.md). Запустить из корня репозитория:

```sh
python Aniyomi/scripts/run_probe.py BrowseAudit --tools .aniyomi-tools/compiler
```

Результат — `Aniyomi/build/browse-audit.json`: первые/вторые страницы, повторное открытие, URL, HTTP-коды и время. Проверки без сети входят в обычный `scripts/check.py`.
