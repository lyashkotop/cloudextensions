# Требования к расширениям

Это список требований владельца, а не заявление, что каждый сайт уже прошёл проверку.
В CI проверяются сборка, целостность пакетов и регистрация провайдеров. Реальные сайты,
воспроизведение и интерфейс CloudStream автоматически не проверяются.

| Требование | Ожидаемое поведение | Состояние |
|---|---|---|
| Полное название | Одно полное название источника в выдаче и открытой карточке; без смены языка после открытия | Общий обработчик исправлен в v64; проверен пример Semyana |
| Описание | Индивидуальное описание ролика, без SEO/рекламы и выдуманного сюжета | Исправлен приоритет полей; отсутствие данных нельзя заполнить выдумкой |
| Длительность | Время в штатном поле CloudStream; не дублировать в описании | Реализован общий разбор; время доступно только когда опубликовано источником |
| Теги | Настоящие метки текущего ролика; без слов из общего рекламного текста | Исправлен пример Semyana; остальные разметки требуют проверки |
| Фильтры категорий | Существующий список BundleSettings применяется к выдаче, карточкам и рекомендациям | Код сохранён; все пути во всех источниках не проверены |
| Разрешённые метки | lesbian, lesbians, лесби, лесбиянки проходят даже при другом совпадении блокировки | Явное разрешение имеет приоритет в blocked() |
| guy и gay | guy не считается совпадением gay; проверка границ слова | Требует регрессионной проверки всех путей |
| Фото | Реальные превью быстро загружаются; корректные Referer, lazy-src и srcset | Обработчики присутствуют; скорость сайта/сети не гарантируется |
| Качество | Выбор реально доступных вариантов потока | Код вариантов сохранён; воспроизведение в CI не проверяется |
| Рекомендации | Непустой список источника; при отсутствии — осмысленный запасной подбор | Исправлен запрос Semyana; кнопка в Android UI не проверялась |
| Без дублей | Повторные ссылки одного видео не повторяются в списках | Общая нормализация присутствует; полное покрытие не подтверждено |
| Поиск RU/EN, 1–2 слова | Оригинальный запрос первым, перевод вторым; объединённая выдача без дублей | НЕ завершено: существуют замена запроса переводом и преждевременное завершение |
| Пагинация | Загружать следующие страницы до конца результатов; не фиксированный обрезанный список | НЕ завершено; у некоторых источников поиск читает одну страницу |
| Пустая выдача | Нет совпадений — пустой результат; тренды не выдаются за совпадения | Защита добавлена, все сайты не проверены |
| Ошибки потока/HTTP | Корректно диагностировать no links found, 403 и другие ошибки | НЕ исправлены все источники; CI не восстанавливает внешние сайты |
| Главная CloudStream | Источники доступны на главной; популярное, новое и категории сайта, где поддерживаются | Существующие разделы сохранены; все жанры каждого сайта не реализованы |
| Скорость | Не задерживать все карточки из-за одного медленного запроса | Есть таймауты; реальные замеры всех источников не выполнены |

## Важные границы требований

- Нельзя гарантировать «всегда найдётся», если совпадений нет. Подстановка случайных трендов запрещена.
- Нельзя гарантировать «всегда откроется», если сайт/сервер потока недоступен.
- Данные отсутствующего описания, тегов, времени или качества не выдумываются.
- Успешная сборка не означает, что источник доступен и все функции работают.
- Сортировка и фильтрация тегов на страницах сайтов требуют отдельной проверки поддерживаемых параметров.

## Следующий проект

Aniyomi: отдельный Android APK с нужными расширениями, доступом к страницам сайтов и
удобным поиском/фильтрацией по тегам. Расширения CloudStream .cs3 с Aniyomi несовместимы.
Возможное добавление аниме 18+ — отдельный будущий этап, не часть текущей публикации.

## Переход Russian на Kotlin

Семь русских источников используют отдельное Kotlin-ядро. Реализованы оригинал + перевод
для запросов из одного–двух слов, удаление дублей между языками и страницами, реальные
GET/POST/HTMX/KVS-курсоры, исходные поля метаданных и блокировки категорий. Пустой поиск
не заменяется трендами. На прочие языки эта отметка о завершении реализации не распространяется.
Проверки конкретных страниц и пределы проверки Android перечислены в `Russian/VALIDATION.md`.
