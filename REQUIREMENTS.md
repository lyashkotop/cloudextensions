# Требования владельца

Это требования к каждому источнику; наличие реализации не означает доступность каждого
внешнего сервера. Android UI и плеер в этой среде не запускались.

UKDevilz использует адаптированный NoodleMagazineProvider phisher98: исходные маршруты поиска сохранены, общие обёртки подключены. См. [описание](English/UKDevilz/README.md).

| Требование | Реализация / проверка |
|---|---|
| Kotlin и отдельные сайты | Все 32 модуля компилируются из Kotlin; один entry point на пакет; старый Smali удалён |
| Полный заголовок | Приоритет полных полей сайта, общий кэш названия; не переводить название при открытии |
| Описание | Настоящее описание текущего видео; удалять рекламу и повтор заголовка; не выдумывать отсутствующий текст |
| Длительность | Штатное поле CloudStream; не генерировать строку времени в plot; неизвестное время не показывать |
| Теги | Только опубликованные метки видео; не дробить заголовок на слова; удалять фрагменты «ра», «для» и общие UI-метки |
| Фильтр | Прежние категории блокировки перенесены в ContentPolicy; выдача, открытие, рекомендации и разделы |
| Исключения | `guy` разрешён. `lesbian/lesbians/лесби/лесбиянки` имеют приоритет для прежних категорий. `anime` и `hentai` в заголовках, а также `3d`, `3dporn`, `3d animated`, `black man` и `pregnant` блокируются при любом теге |
| Превью | Настоящие lazy-src/data-s/srcset, пропуск SVG-заглушек, Referer/User-Agent; проверка сигнатур выборки файлов |
| Качество | Максимум 1080p для заявленного разрешения; 1440p/4K исключены. Только варианты и разрешения, указанные источником; HLS-варианты и экстракторы; Android-проверка не выполнена |
| Рекомендации | Список источника; при отсутствии — реальный поиск по опубликованному тегу; не случайные тренды |
| Без дублей | Нормализация URL; удаление повторов внутри и между страницами поиска/главной |
| RU/EN | Один–два слова: оригинал первым, перевод вторым (UKDevilz использует только введённый запрос), общая выдача без дублей; перевод живым API проверен в обе стороны |
| Пагинация | Страницы upstream-провайдера или реальные GET/POST/KVS/HTMX/JSON-курсоры; фиксированный лимит тремя страницами удалён |
| Пустой поиск | Пустой список при отсутствии совпадений; не подставлять главную/тренды |
| HTTP и no links found | Реальные URL, KVS-декодирование, сохранённые экстракторы, HLS, WebView и Cloudflare-обработчик хоста; все внешние ошибки не устранены |
| Главная | mainPage разделов источника; у TubeSafari — настоящие жанры сайта; набор жанров зависит от провайдера |
| Скорость | Кэш и таймауты, ограниченные параллельные запросы; Xvideos больше не загружает 16 разделов последовательно на один вызов |
| Публикация | Автоматическая компиляция всех модулей; в builds попадает только успешная полная сборка |

Сетевые результаты и примеры ограничений: `imports/english-ten`, `imports/remaining-kotlin`,
`imports/japanese-kotlin`. Изображения и видео во время технической проверки не отображались.
Нет гарантии «всегда найдёт/откроет»: удалённое видео, отсутствие совпадений и запрет сервера
нельзя заменить настоящими метаданными или исправить успешной компиляцией.

Aniyomi: будущий отдельный APK с расширениями и удобными тегами. Пакеты CloudStream `.cs3`
с Aniyomi несовместимы; этот этап не входит в текущую миграцию Kotlin.
