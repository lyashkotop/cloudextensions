# Область работы

По умолчанию работай только с CloudStream (`.cs3`). Aniyomi (`Aniyomi/` и APK) поставлен на паузу до прямой просьбы пользователя вернуться к нему. Пока действует пауза, не меняй, не проверяй, не собирай и не публикуй Aniyomi, в том числе при исправлениях, обновлениях и синхронизации CloudStream.

## Поиск по жанрам

Применяй поиск по вариантам только к известным популярным жанрам, включая «домашнее», «БДСМ», «анал» и «порку», у англо- и русскоязычных источников CloudStream. Японские источники ищут без автоматического перевода. Считай «домашнее», «домашка», «любительское», `homemade`, `amateur` и `amateurs` вариантами одного понятия. Начинай с введённого запроса, затем ищи по русским и английским вариантам. Объединяй результаты поиска по названиям с видео из опубликованных сайтом тегов и рубрик. Убирай повторы, сохраняй пагинацию и не подставляй тренды, если совпадений нет.

## Пустая выдача поиска

Возвращай пустой список и отключай пагинацию, когда источник подтвердил отсутствие совпадений. Используй только подтверждённый блок результатов или данные поискового API. Учитывай редиректы, пустой результат с HTTP 200 и ротацию заглушек. Исключай популярные, рекомендованные и случайные видео из выдачи поиска.

При добавлении или исправлении парсера поиска проверяй обычный запрос и запрос без совпадений. При изменении правил распознавания заглушек добавляй регрессионный пример в проверки сборки GitHub Actions.
