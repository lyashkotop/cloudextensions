# Область работы

По умолчанию работай только с CloudStream (`.cs3`). Aniyomi (`Aniyomi/` и APK) поставлен на паузу до прямой просьбы пользователя вернуться к нему. Пока действует пауза, не меняй, не проверяй, не собирай и не публикуй Aniyomi, в том числе при исправлениях, обновлениях и синхронизации CloudStream.

## Поиск по жанрам

Для русских и английских запросов из 1–3 слов во всех активных CloudStream-плагинах объединяй исходную и переводную выдачу в обоих направлениях. Используй общий кэш переводов CloudStream. Сохраняй порядок оригинальной выдачи перед добавленными совпадениями. Для известных популярных жанров, включая «домашнее», «БДСМ», «анал» и «порку», ищи по русским и английским вариантам. Считай «домашнее», «домашка», «любительское», `homemade`, `amateur` и `amateurs` вариантами одного понятия. Объединяй результаты поиска по названиям с видео из опубликованных сайтом тегов и рубрик. Убирай повторы, сохраняй пагинацию и не подставляй тренды, если совпадений нет.

## Пустая выдача поиска

Возвращай пустой список и отключай пагинацию, когда источник подтвердил отсутствие совпадений. Используй только подтверждённый блок результатов или данные поискового API. Учитывай редиректы, пустой результат с HTTP 200 и ротацию заглушек. Исключай популярные, рекомендованные и случайные видео из выдачи поиска.

При добавлении или исправлении парсера поиска проверяй обычный запрос и запрос без совпадений. При изменении правил распознавания заглушек добавляй регрессионный пример в проверки сборки GitHub Actions.

## Фильтр поиска

При включённом фильтре проверяй заголовок, теги и описание каждой карточки перед показом. Карточки с неподтверждёнными метаданными могут пройти повторную проверку при подгрузке. Сохраняй исключения фильтра и проверяй их в тестах.
