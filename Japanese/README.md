# Japanese Kotlin providers

12 отдельных расширений из phisher98/CXXX и Kraptor123/Cs-GizliKeyif: MissAV,
JAVGuru, JAVHd, JavMost, Javtiful, Javx, SuperJav, Javdoe, JavGG, JavEnglish,
Javangel, Javseen. Дубли объединены; каждый пакет регистрирует один сайт и
необходимые ему экстракторы. Оригинальные коммиты, SHA-256 и лицензия:
[imports/japanese-kotlin](../imports/japanese-kotlin/).

Исправлены код языка ja, загрузка ленивых превью и заголовки изображений.
Поиск переведён с ограничения тремя страницами на API поиска со страницами.
JAVGuru и JavMost получили явное объявление mainPage. Общие библиотеки хоста
не копируются в пакеты; включаются только используемые классы.

HTTP-проверка: 10 из 12 главных страниц ответили 200. MissAV и SuperJav
ответили 403. Javdoe и Javangel требуют отдельной проверки разметки: ответ 200
не подтвердил наличие обычного каталога. Эти четыре источника отмечены beta.
Проверялись ссылки и сигнатуры изображений без отображения содержимого.
Подробные статусы сохранены в http-checks.json; доступность всех фото не заявляется.
Android, CAPTCHA/WebView и воспроизведение здесь не проверялись.

Имена источников имеют только числовые префиксы для сортировки в CloudStream:
1. русские, 2. японские, 3. английские. Изменение имён выполнено по запросу владельца.
