# План развития проекта

**Приоритет: стабильность существующих плагинов.** Новые сайты добавлять после проверки уже подключённых.

Порядок работы: **автоматические проверки → исправление поломок → удобная главная → новые сайты → Aniyomi**.

## 1. Проверка одной кнопкой в GitHub

- [ ] Добавить отдельный ручной GitHub Actions для сетевых проверок.
- [ ] Проверять каждый активный источник: главную, поиск, следующую страницу, адреса обложек, карточку, теги, рекомендации и видеоссылки.
- [ ] Проверять изображения и потоки по HTTP-ответу и формату данных, без просмотра содержимого.
- [ ] Сохранять отчёт по сайтам: этап, результат, HTTP-код, длительность и время проверки.
- [ ] Отделять ошибки провайдера от блокировок сети, приватных роликов и удалённых файлов. Единичный сетевой сбой не считать доказательством поломки кода.

Сборка и проверки общего кода уже выполняются автоматически. Полная сетевая проверка каждого сайта одной кнопкой пока не реализована.

## 2. Двуязычный поиск

- [ ] Включить в сетевой сценарий реальные запросы из одного и двух слов RU↔EN, включая фразы вне локального словаря.
- [ ] Подтверждать оба фактических запроса: исходный первым, перевод вторым.
- [ ] Проверять объединение без дублей и переход по страницам обеих выдач.
- [ ] Проверять отказ сервиса перевода и отсутствие подмены пустого поиска трендами.

Общий координатор, кэш перевода и отдельные реальные проверки уже есть; требуется систематическая проверка всех RU/EN источников.

## 3. Понятная диагностика

- [ ] Привести сообщения к общим понятным причинам: сайт недоступен, нужен вход, файл удалён, страница изменилась, превышено время ожидания.
- [ ] Добавлять в технический отчёт источник и этап ошибки.
- [ ] Исключить ложный успех: HTTP 200 страницы не доказывает доступность видео.

## 4. Удобная главная

- [ ] Для каждого сайта проверить реальные разделы Latest, Popular и Trending там, где они существуют.
- [ ] Добавлять только настоящие категории/жанры сайта.
- [ ] Проверять листание разделов и отсутствие дублей.

У Noodle Magazine Popular и Trending уже подключены. Возможность выбора разделов и вид главной зависят также от интерфейса CloudStream.

## 5. Качество карточек и фильтрация

- [ ] Продолжить проверку всех источников на разных реальных роликах: полное название, единый выбранный вариант в выдаче и карточке.
- [ ] Проверять обложку в поиске и после открытия, включая нужные Referer/cookies и временные ссылки.
- [ ] Сохранять только описание ролика; рекламный текст убирать, отсутствующее описание оставлять пустым.
- [ ] Использовать подтверждённые теги/категории ролика; исключить SEO-ключи, фрагменты слов и выдуманные значения.
- [ ] Проверять рекомендации: реальные связанные ролики или честно обозначенная подборка по тегу; без подмены пустого поиска.
- [ ] Проверять ранний отсев по названию и тегам, приватные ролики, качество видео и доступность ссылок.
- [ ] Измерять задержку холодного поиска и повторного запроса с кэшем.

Общие исправления и проверка первых 10 кандидатов внедрены. Неуспешное получение метаданных не подтверждает теги, а интерфейс CloudStream сам определяет число строк названия и предварительную загрузку картинок.

## 6. Структура и сопровождение

- [ ] Поддерживать минимальный шаблон нового провайдера и инструкцию по исправлению одного сайта.
- [ ] Сохранять особенности сайта в его папке, общую сеть/перевод/фильтрацию — в common.
- [ ] Добавить таблицу состояния сайтов с датой последней реальной проверки и ссылкой на отчёт.
- [ ] Сохранять отключённые источники в Unused и исключать их из сборки и индекса.
- [ ] Следить за размером пакетов и отсутствием лишних зависимостей.

Разделение по сайтам, Kotlin, общий код и папка Unused уже используются.

## 7. Aniyomi — отдельный следующий этап

- [ ] Оценить возможности API и совместимость с актуальным приложением.
- [ ] Сделать отдельные расширения с удобным поиском по настоящим тегам и фильтрами.
- [ ] Перенести подходы и проверки; CloudStream-пакеты напрямую не переносить.
- [ ] Отдельно оценить сборку APK с набором расширений, его обновление и сопровождение.

Это будущая работа; готовая Aniyomi-сборка сейчас не заявляется.
