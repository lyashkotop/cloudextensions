# UKDevilz — NoodleMagazine от phisher98 с адаптацией

Базовый источник: phisher98/CXXX, commit f1bb71a85c62746e9b70b6e68e67fc48c005d116. Исходная лицензия сохранена в LICENSE.upstream. Изменения и контрольные суммы — provenance.json.

Поиск сохраняет исходный адрес /video/$query?p=$page, переданный номер страницы, div.item и порядок элементов. Главная сохраняет исходные разделы автора. Поисковый перевод и дополнительная языковая ветка отключены. HTML запрашивается с английскими cookies; это настройка отображения сайта, а не изменение запроса. Одинаковые реальные ответы сайта старый и новый парсер разбирают в тот же список URL. Живая выдача разных запросов во времени может отличаться на стороне сайта.

Источник подключён к ReliableProvider: фильтры, проверенный префикс из 7 видимых карточек, предзагрузка в общий кэш Coil и единое название списка/карточки. Блокируемые и непроверенные результаты в начало выдачи не проходят; остальная допустимая выдача не обрезается.

Обложки: lazy-атрибуты, src/srcset и постоянные Referer/User-Agent, сохранение реальной обложки при открытии. Теги читаются из #videoTagsBar a.vtag, английский вариант берётся с сайта или переводится целой подписью с кэшем. SEO keywords и слова из названия не используются. Описание пустое, длительность в штатном поле.

Качества: только объявленные window.playlist.sources, JSONTokener вместо обрезки по точке с запятой, отдельные названия вариантов, реальная числовая метка качества. Перед выдачей выполняется короткая HTTP-проверка с заголовками плеера; недоступный вариант исключается. Интерцептор сохраняет Range и If-Range для перемотки/переключения.

Проверки и фактические ограничения доступа к CDN: [отчёт](../../imports/phisher-noodle-adapted/README.md).
