# UKDevilz — оригинальный NoodleMagazine от phisher98

По требованию владельца слот UKDevilz заменён оригинальным NoodleMagazineProvider из [phisher98/CXXX](https://github.com/phisher98/CXXX/tree/f1bb71a85c62746e9b70b6e68e67fc48c005d116/NoodleMagazineProvider).

Файл провайдера скопирован без изменений, включая package com.CXXX, mainUrl, разделы главной, поиск, обработку карточек, ссылок и interceptor. Контрольная сумма и commit указаны в provenance.json. Исходная лицензия сохранена в LICENSE.upstream.

Меняется только регистрационное имя на `3. UKDevilz`. Внутренний ID пакета UKDevilz сохранён: обновляется уже установленное расширение. Провайдер зарегистрирован напрямую, как в оригинальном plugin entry; общие ReliableProvider/AdaptedProvider, дополнительные фильтры, предзагрузка и правила перевода этой копии не подключены. Исходные разделы Latest/Onlyfans/Latina/Hentai и остальные разделы оригинала сохраняются.

Отдельный русский Noodle Magazine остаётся нашей адаптированной версией и этим изменением не затрагивается. Прежняя реализация UKDevilz доступна в истории Git.
