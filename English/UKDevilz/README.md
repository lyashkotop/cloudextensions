# UKDevilz

Английский профиль сайта: ui_lang=en и Accept-Language=en. При наличии data-video-title-translations/data-tag-translations используются английские значения, объявленные самим сайтом. Если английского заголовка нет, сохраняется полное исходное название; новое название не сочиняется.

Поисковый запрос отправляется только как введён: UKDevilz и Noodle Magazine исключены из автоматического RU↔EN объединения. Cookies UKDevilz — ui_lang=en. Язык интерфейса сайта не изменяет текст запроса пользователя.

Описание всегда пустое. Настоящие теги карточки, оставшиеся на русском, переводятся целыми подписями в английский с общим кэшем. Существующие английские теги сохраняются. При недоступности перевода неподтверждённые русские подписи в карточке не отображаются; новые теги из названия не создаются. Для слова «член» используется контекстный перевод penis, а не member.

Плеер: общий разбор window.playlist.sources и качества label. UKDevilz возвращает только потоки с успешным коротким HTTP-запросом; если один CDN не отвечает, его качество пропускается. Это проверка доступности в момент запроса, не гарантия доступности CDN в будущем.
