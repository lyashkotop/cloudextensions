# TubeBDSM

Агрегатор с переходом к внешним источникам: прямые MP4, HLS/DASH, Next.js firstVideo, data-sources, JWPlayer sources, iframe и SDK-экстракторы. При наличии подходящего установленного провайдера используется также его обработчик.

Добавлены метаданные и настоящие рекомендации внешних сайтов. Лимит качества 1080p сохраняется, вертикальные ролики именуются по короткой стороне. Отсутствующее настоящее описание остаётся пустым. Авторизация, платный доступ и удалённые файлы не обходятся.

[Результаты реальных проверок и оставшиеся ограничения](../../imports/tubebdsm-playback/README.md).
