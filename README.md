# CloudExtensions для Aniyomi — v6

[Скачать подписанный APK](https://raw.githubusercontent.com/lyashkotop/cloudextensions/aniyomi-builds/CloudExtensions.apk?v=6)

32 источника. Версия 14.6 / код 6; тот же ключ подписи для обновления поверх v3/v4/v5. Это расширение для установленного Aniyomi.

Обе вкладки используют проверенные маршруты каждого сайта без предварительного открытия главной. Соседняя вкладка прогревается в фоне; повторные запросы используют кэш. Исправлены выбор новинок/популярного, смешивание соседних лент, сохранение сортировки при пагинации, повторы ForcedCinema и пустые ответы Strip2.

Проверены все 32 источника: 31 популярная лента и 30 лент новинок загрузились. MissAV в тестовой сети отвечает 403; рабочая общая лента новинок Xnxx пока не найдена. У PornVideos популярное — сейчас смотрят, у SickJunk — по комментариям.
