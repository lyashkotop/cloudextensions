# CloudExtensions


**[План развития и список задач → ROADMAP.md](ROADMAP.md)**

36 отдельных расширений CloudStream на Kotlin: **12 Russian, 2 Japanese, 22 English**.
Один сайт — один устанавливаемый `.cs3`. Общая логика не копирует в пакет другие сайты
или библиотеки приложения.

## Подключение

CloudStream → Настройки → Расширения → Добавить репозиторий:

```text
https://raw.githubusercontent.com/lyashkotop/cloudextensions/main/repo.json
```

После добавления установи нужные сайты. Ссылка добавляет список, а не устанавливает все
расширения автоматически. Прежний общий StreamBundle следует удалить, чтобы не дублировать
источники. Ссылка репозитория остаётся постоянной при обновлениях.

Расширения группируются префиксами `1 · RU`, `2 · JA`, `3 · EN`. В списке источников
используются только цифры `1.`, `2.`, `3.` перед именем. Внутренние ID расширений сохранены;
старые фильтры и закладки могут хранить прежние имена источников.

## Исходники и сборка

- `Russian/`, `Japanese/`, `English/`: каждый сайт имеет `plugin.json`, Kotlin-провайдер и собственную регистрацию.
- `common/kotlin/`: HTTP, метаданные, превью, фильтры, перевод, пагинация, воспроизведение и адаптер импортированных реализаций.
- `common/tests-kotlin/`: проверки контрактов общего кода.
- `common/probes/`: техническая проверка сохранённых настоящих страниц без отображения медиа.
- `scripts/`: компиляция, проверка отдельных пакетов и публикация.
- `assets/icons/`: настоящие иконки конкретных сайтов; `assets/repository.png` — иконка репозитория.
- `imports/`: происхождение заимствованного кода, коммиты, лицензии и результаты HTTP-проверок.

Smali и прежние Java-парсеры удалены из актуальной сборки; они доступны в Git-истории
до `ed12096`. Менять код сайта можно в его собственной папке. Общий код следует менять,
когда исправление относится к нескольким источникам. Пакеты изменённых провайдеров пересобираются автоматически. При изменениях общего кода или сборки пересобираются все пакеты.

После коммита в `main` [GitHub Actions](https://github.com/lyashkotop/cloudextensions/actions)
компилирует изменённые модули, проверяет DEX, единственную регистрацию каждого источника, манифесты,
размеры и SHA-256. Только успешная сборка обновляет ветку `builds` и `plugins.json`.
Версия нового пакета равна `64 + номер запуска workflow`. Переиспользованные пакеты сохраняют свои версии. Неудачная сборка сохраняет предыдущие файлы.
В индексе каждому пакету соответствует отдельный URL с его версией. Адрес подключения репозитория остаётся прежним.

Для локальной сборки нужны Python 3.9+ и Java 21:

```sh
python common/tools/fetch_tools.py --directory .tools
python scripts/build_repository.py --version 78
```

Результат — `.release/`. Компилятор, SDK и зависимости закреплены SHA-256.
Каждый Kotlin-пакет включает только достижимые из его точки входа классы;
CloudStream, Kotlin, HTTP и JSON-библиотеки предоставляет приложение.

## Проверка источников

[Check CloudStream sources](https://github.com/lyashkotop/cloudextensions/actions/workflows/site-health.yml)
ежедневно проверяет девять источников. Запусти workflow с параметром `all` для всех активных плагинов.
По умолчанию проверяются две разные карточки на источник. Для ручного прогона укажи `samples: 10`
в GitHub Actions или `--samples 10` в `scripts/check_sites.py`.
Отчёт содержит результаты открытия главной, поиска, второй страницы, обложек, тегов, рекомендаций
и видеопотока. Доступность проверяется HTTP-запросами и сигнатурами файлов. Для плееров, которым
нужен WebView, в отчёте указан Android.

## Поведение и пределы проверки

**UKDevilz** основан на NoodleMagazineProvider из phisher98/CXXX: исходная схема поиска сохранена, исправлены обложки, теги и качества, подключены общие обёртки. [Подробности и происхождение](English/UKDevilz/README.md).

Оригинальный запрос из 1–3 слов объединяется с переводом RU↔EN в исходном порядке (UKDevilz ищет обычные слова в исходном виде),
повторные ссылки удаляются. Для известных жанров на русских и английских источниках поиск дополнительно использует варианты на обоих языках и опубликованные теги и рубрики. Используются настоящие страницы/курсоры сайта; пустая выдача
не заменяется трендами. Фильтр категорий применяется к выдаче, рекомендациям и открытию.
`guy` разрешён. Все слова из списка блокировки проверяются в заголовке и каждом теге.
Исключения `lesbian/lesbians/лесби/лесбиянки` и связанные с ними слова разрешают видео при совпадении в заголовке или теге.

Главная каждого расширения перемешивает карточки внутри разделов при каждом обновлении.
Если следующая страница отвечает быстро, часть её карточек попадает в первый экран; остальные остаются доступны при прокрутке. Noodle Magazine использует собственную случайную выборку страниц.

Названия берутся из полей источника и согласуются между списком и карточкой. Описания
и теги не составляются из слов заголовка. Длительность сохраняется в штатном поле CloudStream,
без повторной строки «Длительность: …» в описании. Отсутствующие данные не выдумываются.

Проверки реальных страниц и сигнатур превью выполнены без просмотра изображений/видео.
Это не проверка Android-плеера, WebView или каждого ролика. Известны внешние ограничения:
PunishBang, SpankBang, MissAV и SuperJav отвечали 403; часть исходных embed-ссылок TubeSafari
удалена (404); у Strip2 встречались 504 превью. Доступность каждого сервера не гарантируется.

[остальные Kotlin-модули](imports/remaining-kotlin/README.md), [Japanese](Japanese/README.md).

## Aniyomi

Отдельный APK на все активные источники, с исходниками и воспроизводимой сборкой: [Aniyomi/](Aniyomi/). Он устанавливается в Aniyomi; CloudStream-пакеты остаются отдельными.
