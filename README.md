# CloudExtensions

Репозиторий расширений CloudStream с автоматической сборкой GitHub Actions.
Один сайт — один устанавливаемый `.cs3`. В исходниках: **Russian**, **English**, **Japanese**.

В списке расширений порядок: **русские → японские → английские**. CloudStream сам
сортирует имена, поэтому названия расширений имеют префиксы `1 · RU`, `2 · JA`, `3 · EN`.
В списке источников также используются цифры `1.`, `2.`, `3.` перед именем.
Внутренние ID расширений сохранены; старые фильтры и закладки могут хранить прежние имена источников.

## Подключить в CloudStream

Настройки → Расширения → Добавить репозиторий:

```text
https://raw.githubusercontent.com/lyashkotop/cloudextensions/main/repo.json
```

После добавления репозитория установи нужные расширения из списка. Сама ссылка добавляет
список, а не устанавливает автоматически все сайты. Если был установлен общий StreamBundle,
удали его перед переходом на отдельные расширения, чтобы не дублировать источники.

## Как выходят обновления

1. Правки исходников попадают в `main`.
2. Actions компилирует Kotlin-провайдеры и поддерживаемый Java-код, собирает оставшиеся smali-модули и проверяет отдельную точку входа каждого сайта.
3. Только после успешной сборки ветка `builds` получает `.cs3`, `plugins.json`, размеры и SHA-256.
4. Версия равна `64 + номер запуска workflow`; номера в манифестах и списке совпадают.
5. При проверке обновлений CloudStream получает новые пакеты по постоянным URL.

Сначала проверяй зелёный статус в [Actions](https://github.com/lyashkotop/cloudextensions/actions).
Пока первая сборка не завершится успешно, список `builds/plugins.json` ещё недоступен.
Ошибочная сборка не заменяет предыдущие готовые файлы. Pull request только собирается, без публикации.

## Где редактировать

- `Russian/` — русские провайдеры на Kotlin: `src/main/kotlin`, отдельные регистрации и `plugin.json`.
- `Japanese/` — 12 адаптированных Kotlin-провайдеров.
- `English/` — 11 Kotlin-провайдеров; остальные 16 переводятся с прежней реализации.
- `common/kotlin/` — общие Kotlin-парсеры, HTTP, фильтры, перевод, пагинация и адаптер импортированных провайдеров.
- `common/java/` — поддерживаемые Java-обработчики метаданных, автоматически компилируемые в сборке.
- `common/smali/` — общая библиотека, парсеры и другая логика в редактируемом байткоде.
- `reference/java/` — исторические читаемые файлы для справки; они **не компилируются**. Рабочие правки этих классов делаются в соответствующем smali.
- `scripts/` — сборка репозитория и публикация.
- `assets/icons/` — иконки конкретных сайтов; `iconUrl` у каждого расширения указан в его `plugin.json`.
- `common/tools/` — закреплённые компиляторы и контрольные суммы зависимостей.
- `REQUIREMENTS.md` — требования владельца и реальное состояние каждого пункта.

32 из 48 провайдеров используют Kotlin: 9 русских, 12 японских и 11 английских.
Смешанная сборка управляется Python, компиляторы и SDK закреплены контрольными суммами. Локальная сборка:

```sh
python common/tools/fetch_tools.py --directory .tools
python scripts/build_repository.py --version 65
```

Требуются Python 3.9+ и Java 21. Папка `.release/` содержит тот же формат, что публикуется в `builds`.

Kotlin-пакеты содержат только свой провайдер, регистрацию и используемые общие классы.
Kotlin-пакеты занимают примерно 15–80 КБ; первая английская партия — 40–52 КБ.
SDK и остальные сайты туда не копируются. Старые пакеты других языков пока включают прежнюю общую библиотеку.
Имена классов и ID источников сохранены. При изменении общего кода набор пересобирается.

## Известные ограничения

Работоспособность сайтов в CI не проверяется. PunishBang/MissAV отвечали 403, пустой поиск
YouJizz не исправлен. Общий Kotlin-код объединяет оригинальный и переведённый запрос из 1–2 слов и сохраняет
пагинацию источника. TubeSafari пока нуждается в отдельном переходе и проверке метаданных. Сборка и публикация не исправляют эти проблемы.
Сведения и интерфейс, которых источник не предоставляет, не подменяются выдуманными.

Проверки метаданных, унаследованные от v64, сохранены. Новые массовые проверки реальных
сайтов пока не добавлены по просьбе владельца. Полные ограничения v64: `common/CHANGES-RU.md`.

Импортированные девять расширений CloudstreamAdult и их ограничения: [imports/CloudstreamAdult](imports/CloudstreamAdult/README.md).

Состояние перехода русских сайтов на Kotlin: [Russian/VALIDATION.md](Russian/VALIDATION.md).

Адаптация присланного Noodle Magazine: [Russian/NoodleMagazine](Russian/NoodleMagazine/README.md).

Японские Kotlin-модули и ограничения проверки: [Japanese](Japanese/README.md).

Первая английская Kotlin-партия, Poebon и живая HTTP-проверка: [imports/english-ten](imports/english-ten/README.md).
