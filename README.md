# Cloud Extensions for Aniyomi

[Download signed APK](https://raw.githubusercontent.com/lyashkotop/cloudextensions/aniyomi-builds/CloudExtensions.apk)

32 active sources, API 14, Android 8+. Install the APK, then trust the extension in Aniyomi → Browse → Extensions. This is an extension, not a standalone Aniyomi application.

[Source code and rebuild instructions](https://github.com/lyashkotop/cloudextensions/tree/main/Aniyomi). Source revision: 6b3033d. Signature verification and native filter contracts passed. The Android UI/WebView path has not been device-tested here. MissAV and some CDNs require Cloudflare access; deleted/unavailable records are not counted as working.

The private signing key is not published. Future updates must use the same signing key and a higher version code.
