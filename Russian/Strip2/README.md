# Strip2 previews

Часть карточек выдачи использует встроенный `data:image/...` в `src`, а настоящую
ссылку хранит в `data-s`. Общий Kotlin-парсер теперь читает `data-s` и пропускает
встроенную заглушку. Заголовки загрузки превью согласованы с запросами сайта.

Добавлена регрессионная проверка для такой разметки. Проверка URL фотографий выполнялась
без отображения изображений. Ранее добавленное обновление HTML с истёкшими подписанными
ссылками сохранено.
