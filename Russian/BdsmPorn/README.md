# BDSM-Porn.cc

Русскоязычный каталог. Провайдер отдаёт приоритет русскому через HTTP-заголовок Accept-Language. Языковой cookie в сохранённых ответах сайта не обнаружено.

Провайдер следует нумерованным страницам сайта и ищет совпадения по заголовкам в каталоге. Разметка главной, разделов и карточек подтверждена архивными копиями. При воспроизведении провайдер использует ссылку живого плеера.

Живой сайт, обложки и видео при проверке возвращали Cloudflare HTTP 403. Пакет использует штатный WebView CloudStream для проверки сайта. Доступ и воспроизведение на Android требуют проверки.
