# Порно Молоко

Расширение CloudStream с главной по разделам, переводом коротких запросов RU↔EN и общими фильтрами. Описания, категории, длительность и оценки берутся из карточки источника. Обложки берутся из каталога и настроек плеера.

Страницы разделов используют штатную пагинацию сайта. Если серверный поисковый указатель теряет запрос, расширение продолжает поиск по названиям на доступных страницах каталога. Первые совпадения выдаёт поисковый движок сайта. Дальше идут только карточки с совпадением заголовка, без подстановки общего каталога. При проверке сайт возвращал HTTP 404 начиная с `/All-11.html`, хотя продолжал ссылаться на эти страницы.

На проверенных страницах плеер публиковал один MP4, а пункты 360p, 480p и 720p в меню скачивания указывали на один файл. Расширение отдаёт исходный поток.

В доступном каталоге проверены 1000 заголовков на десяти страницах, все содержали кириллицу. Для обычного русского запроса расширение пропускает дополнительный английский запрос. Для английского ввода сохраняется поиск по русскому переводу.
