# Russian — Kotlin providers

Все семь провайдеров имеют исходники `.kt` в `Russian/<Site>/src/main/kotlin/`.
ID, имена источников и классы провайдеров сохранены, чтобы обновление не создавало дубликаты.
Старые smali-версии доступны в истории до коммита перехода.

- [Ebalka](Ebalka/)
- [Huyamba](Huyamba/)
- [Perdol.net](Perdol/)
- [ProstoPorno](ProstoPorno/)
- [Semyana](Semyana/)
- [Strip2](Strip2/)
- [Vpoisk](Vpoisk/)

Каждый сайт задаёт свою разметку, поиск и реальные разделы. Общая Kotlin-реализация:
`common/kotlin/com/cloudextensions/russian/`.

- `RussianProvider.kt`: главная, согласованные названия, двуязычный поиск, рекомендации.
- `Metadata.kt`: исходные теги, описание, точная длительность и превью.
- `Pagination.kt`: реальные ссылки, POST-формы, HTMX и KVS AJAX-курсоры.
- `Network.kt`: кэш 30 секунд, ограничение параллельных запросов, отмена и таймауты.
- `ContentPolicy.kt`: прежний список блокировок; lesbian/lesbians/лесби/лесбиянки разрешены.
- `Translation.kt`: оригинальный запрос первым, перевод вторым для одного–двух слов.
- `Playback.kt`: источники плеера, реальные варианты HLS, экстракторы CloudStream и WebView.

Исходные описания не заменяются рекламой. Когда текста нет, описание остаётся пустым; длительность передаётся в штатном поле CloudStream. Для похожих видео сначала используются
блоки сайта, затем поиск по реальному тегу. Тренды не подставляются в пустой поиск.

HTTP 404 в поиске означает пустую выдачу. Другие HTTP-ошибки не выдаются за успех.
Для Strip2 обновляется HTML источника, поскольку кэш сайта может содержать истёкшие
подписанные ссылки на изображения и видео. HTTP-статус картинки не подменяется.

Kotlin компилируется на закреплённом официальном SDK CloudStream. SDK, стандартная
библиотека Kotlin, OkHttp и код других провайдеров не включаются в русские `.cs3`.
Python управляет смешанной сборкой: остальные языки пока используют прежнюю реализацию.

Проверки и ограничения: [VALIDATION.md](VALIDATION.md).
