# Noodle Magazine — Kotlin

Основа — `NoodleMagazineProvider.kt` и `NoodleMagazinePlugin.kt`, предоставленные владельцем
(исходный package `com.CXXX`). Сохранены ID расширения, имя источника, класс провайдера
и точка входа из предыдущей версии репозитория.

Причина прежней пустой выдачи: использовались другой адрес и универсальный поиск `/search/`.
В проверяемой сети старый адрес получил отказ прокси 403. У предоставленного варианта
используются `https://tyler-brown.com/video/<query>?p=<zero-based-page>` и другая разметка.

Изменения при адаптации:

- Поиск и главная начинаются с `p=0`, а не пропускают первую страницу.
- Поиск читает только `#list_videos`: соседние случайные рекомендации не являются результатами.
- Оригинальный запрос идёт первым; для одного–двух слов добавляется перевод и удаляются дубли.
- Следующие страницы и объединение языков не имеют фиксированного лимита карточек.
- Используются настоящие заголовок, теги, описание и точная длительность страницы.
- Рекомендации берутся со страницы; запасной вариант — поиск по настоящему тегу.
- Ссылки и подписи качества читаются из JSON playlist; отсутствие ссылок возвращает false.
- Сохранён User-Agent плеера из присланного кода, при этом Range/If-Range не теряются.
- SDK и код других провайдеров не попадают в пакет; общие классы отбираются по зависимостям.

## Проверка

Реальные HTTP-ответы нового адреса: `guy` и `iron` — 24 настоящие карточки, `over` — 0;
заведомо отсутствующий запрос — 0, без случайных рекомендаций. Вторая страница `guy`
вернула ещё 24 карточки. Все эти HTTP-запросы вернули 200.

На выбранной странице видео Kotlin-парсер получил полное название (51 символ), три
исходных тега, длительность `04:55`, описание (78 символов). В JSON плеера — два варианта
источника. Само видео не скачивалось и не отображалось.

Android CloudStream, воспроизведение, перехватчик запросов и интерфейс качества здесь
не запускались. Успешная компиляция и разбор playlist не являются проверкой воспроизведения.

Проверка изображения с выбранной страницы остановилась на CONNECT-прокси: хост CDN
`cdn2.pvvstream.pro` получил 403 в этой среде. Это не подтверждает доступность превью
или видео с CDN на устройстве пользователя; ошибку не скрываем и картинку не подменяем.

По умолчанию запросы к самому сайту используют его cookie `ui_lang=ru` и заголовок Accept-Language ru. Проверены реальные ответы: при ru все 24 названия содержат кириллицу, при en — 0 из 24. Это выбор языка сайта, а не перевод названий внутри плагина.
