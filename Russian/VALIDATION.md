## Реальные HTTP-ответы и HTML

- Все семь главных страниц и семь выбранных страниц видео вернули HTTP 200. Изображения не отображались: проверялись статусы и сигнатуры файлов.
- Kotlin-парсер выполнили на сохранённом HTML этих ответов: во всех семи примерах получены название, теги, превью и точная длительность.
- Для каждого сайта проверены `guy`, русский эквивалент и заведомо отсутствующий запрос. Общая выдача оригинала и перевода непустая; отсутствующий запрос не подменяется трендами.
- Полученные Kotlin-парсером реальные курсоры второй страницы отправлены на все семь сайтов. Ответы HTTP 200, обнаружены дополнительные карточки.
- На Strip2 старое подписанное превью вернуло 410. Обновление HTML источника дало новую ссылку с HTTP 200; такое обновление включено в Network.kt.
- Semyana в проверенном примере не предоставляет содержательного описания. Текст не выдумывается; в описании остаётся точная длительность.

## Пределы проверки

Это проверки HTTP, исходных полей, парсеров и пакетов. Они не заменяют запуск Android CloudStream. Воспроизведение, WebView, кнопки и выбор качества в Android здесь не подтверждены. Проверена одна страница видео на сайт, а не весь каталог.

Разделы главной берутся из доступных ссылок сайта. У ProstoPorno ссылка `/categories/` сейчас отдаёт 404, поэтому непроверенные категории не добавлены.

Подробные результаты без содержимого страниц: [validation.json](validation.json). Сборка запускает локальные проверки автоматически. Реальные HTTP-проверки проведены отдельно; CI не обращается массово к сайтам.
