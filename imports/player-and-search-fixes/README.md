## Правило RU/EN

Все 34 активных RU/EN источника используют один координатор ReliableProvider:
исходный запрос первым, перевод вторым, общий список без дублей, страницы обоих запросов.
Вложенные провайдеры выполняют только переданный запрос и не переводят его повторно.
Одно/два слова переводятся в обе стороны. Общий Android SharedPreferences-кэш и координация
запросов между расширениями уменьшают повторные обращения к сервису перевода.
Основной запрос теперь идёт на clients5.google.com с разбором формата Chrome; два адреса
/single сохранены как резервные. При проверке /single отвечали HTTP 429, а Chrome endpoint
возвращал HTTP 200 и настоящий перевод. Локальный словарь частых слов уменьшает задержку.
Недоступность всех внешних адресов всё ещё может помешать переводу произвольного слова.

На настоящих PornVideos.rs, XRares, ProstoPorno, BDSMX проверены 16 запусков:
парень/guy и два слова/two words. В каждом записаны оба фактических вызова поиска,
включая исходный. Сетевые ответы не заменялись; результаты в bilingual-results.json.
ProstoPorno выбирает только ссылки /videos/, а не модели/актрис.
Ещё четыре сетевые проверки PornVideos.rs/XRares с «молодая женщина» и «young woman»
прошли без словарных подсказок: оба запроса выполнены в обе стороны, исходный первым.
PornVideos.rs вернул 8 карточек, XRares — 0 реальных совпадений (без подмены трендами).
Сырые итоги: bilingual-network-results.json.
Фильтры проверяются также общим слоем, добавлены cuckold/куколд/trans и формы слов;
явное разрешение lesbian/лесби сохраняется по требованию владельца.

## Состояние указанных файлов

Вызван реальный SDK loadLinks на данных из пользовательских логов, затем проверены первые
байты потоков без воспроизведения. BDSMX, HurtSex, ForcedCinema дали MP4 HTTP 206;
TubeSafari дал HLS и MP4 HTTP 206. У BDSMX на главной 53 карточки после фильтра.
Приведённый Epawg — приватный ролик, сайт требует входа. У приведённого PornVideos.rs
файл на Nonkporno возвращает 404 даже обычным GET. Удалённый файл не восстановлен;
теперь возвращается точная ошибка сервера, а не фиктивная ссылка. CosXPlay по просьбе
владельца отключён, его исправления и исходники оставлены в Unused.
