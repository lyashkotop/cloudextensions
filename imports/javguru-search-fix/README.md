# JavGuru: обложки поиска, 2026-11-16

Поисковые обложки теперь используют проверенный путь `/wp-content/uploads/` на самом jav.guru вместо дополнительного домена cdn.javmiku.com. Путь файла сохраняется. Изменение локально для JavGuru; выдуманных картинок/иконок вместо обложек нет.

Разбор карточки общий для поиска, главной и рекомендаций: полное название, изображение и заголовки Referer/User-Agent. Карточки выбираются из inside-article без повторного разбора внешней row. Адрес поиска кодируется URLEncoder, следующая страница определяется по настоящей ссылке сайта.

Проверка через настоящий SDK и ReliableProvider(AdaptedProvider(JavGuru())): запросы guy/woman, страницы 1 и 2, по 24 карточки. Все 96 адресов обложек на origin ответили HTTP 206 image/jpeg, проверены первые байты JPEG, без просмотра изображений. Открытие первой карточки guy сохранило её поисковую обложку. Исходный CDN также доступен из проверочной среды: проблема конкретного Android-устройства здесь не воспроизведена; изменение устраняет зависимость запроса изображения от второго домена, но проверка интерфейса Android не проводилась.

Итоги — search-live.json; исходник проверки — common/probes/JavGuruSearchProbe.kt. Время в отчёте включает получение выдачи и проверку всех 24 изображений с параллелизмом 4, а не только поиск.

Остальные японские источники перенесены в Unused: JavGG, Javangel, Javdoe, SuperJav. В Japanese остались только MissAV и JavGuru; всего активны 36 пакетов. Уже установленные отключённые расширения CloudStream нужно удалить в приложении самостоятельно.
