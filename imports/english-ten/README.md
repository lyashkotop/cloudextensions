# Первая английская Kotlin-партия и Poebon

BDSMX, Beeg.porn, BoundHub, CosXPlay, DarknessPorn, Epawg, EPorner, ForcedCinema,
hcBDSM, Heavy-R и TubeBDSM; новый русский Poebon.

Пять реализаций адаптированы из указанных в `provenance.json` репозиториев с сохранением
регистрации экстракторов. Остальные используют собственные Kotlin-профили и общий парсер;
BDSMX получает каталог и метаданные из настоящего JSON API сайта.
Общий адаптер добавляет фильтр, объединение RU/EN, дедупликацию, заголовки превью,
согласование названий и связанные видео из настоящих тегов. Никакой подстановки трендов в пустой поиск.

2026-11-15: все 12 каталогов/API ответили HTTP 200. По два выбранных превью каждого
HTML-каталога и одно превью BDSMX ответили 200 с сигнатурой изображения. Страницы:
0,68–2,95 с. Числа и результаты сохранены в `http-checks.json`; это выборка, а не гарантия
каждого файла. Изображения и видео не просматривались.

Локальная сборка 48 отдельных пакетов прошла 44 Java и 43 Kotlin проверки.
Нативные пакеты этой партии: 40–52 КБ. Номера длительности больше не генерируются в
описаниях ни одним модулем; поле duration CloudStream сохранено.

TubeBDSM — агрегатор с внешними ссылками: воспроизведение всех внешних хостов
в Android не проверено. Сборка, HTTP и заголовки картинок не доказывают работу плеера,
WebView или обхода Cloudflare на устройстве.
