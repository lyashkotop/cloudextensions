# Метаданные и фильтр первых десяти, 2026-11-16

Общий ReliableProvider фильтрует заголовки всей выдачи сразу. До возврата страницы дополнительно проверяет название и теги первых 10 кандидатов. Параллелизм 4, бюджет попытки 3500 мс включая очередь, кэш решения 5 минут/128 URL. Неуспешная/просроченная проверка не скрывает карточку без доказательств: её название всё равно прошло первичный фильтр, но теги не подтверждены. После исключения роликов следующие, ещё не проверенные кандидаты могут сдвинуться вверх. Это проверка первых 10 исходных кандидатов, а не гарантия для каждого элемента бесконечной ленты.

Для RussianProvider проверяется только HTML/метаданные без получения рекомендаций и извлечения потоков. Другие реализации используют load(); полученная карточка повторно используется при открытии. Провайдеры всех 33 активных пакетов проходят ReliableProvider, включая MissAV. Порядок исходного и переведённого поиска сохранён, результаты не обрезаются до 10.

Название: предпочтение title/alt перед визуальным сокращением; короткий кэш заменяется полным продолжением. Для усечений с многоточием есть ограниченное по времени получение заголовка страницы, параллельно с максимум 4 запросами. Заголовок страницы/VideoObject предпочтительнее SEO og:title с названием сайта. Если сайт не предоставил полный заголовок или запрос не удался, полный текст не выдумывается. Число строк плитки CloudStream задаёт приложение.

Описание: общий отсев рекламных шаблонов, отказ от SEO meta description как запасного описания, отключено первичное SEO-описание в EPorner/XVideos. Остаются описание самого видео из его блока или VideoObject, прошедшее очистку. Пустое описание разрешено.

Теги: SEO keywords больше не используются как запасные теги, site-specific селектор заменяет общий. Semyana использует только категории ролика .tax-cats, без автоматически расширяемых tax-tags/tax-extra с обрывками. UKDevilz берёт видимые #videoTagsBar a.vtag вместо JSON keywords. ThisVid исключает thumb.private/icon-private до формирования карточки в выдаче/главной/рекомендациях.

Настоящие HTTP-проверки: 9 открытых страниц (по 3 BDSMStreak/UKDevilz/Semyana), совпадение полного названия с h1, очистка описания и теги из подтверждённых блоков. На /private/ ThisVid найдено 36 приватных карточек, в результат не попала ни одна. Итоги live-results.json. Также отдельно сопоставлены alt/h1 на ещё 8 страницах BDSMStreak: совпадение полное. Android UI не проверялся.

Полный поиск guy через реальные API с новой проверкой: BDSMStreak 2688 мс, UKDevilz 2697, Semyana 1739, ThisVid 1556. Повтор в том же процессе 2–34 мс; это измерения среды, не обещание такой скорости на любом устройстве. search-benchmark.json.

98 проверок общего кода прошли. Отдельная детерминированная SDK-проверка FirstTenSearchTest.kt проверяет отсев по заголовку и тегу, лимит 10, полный заголовок, кэш и очистку plot. Она не заменяет сетевые проверки выше.

YouJizz, PunishBang, Epawg сохранены в Unused и исключены из сборки/индекса. Установленные ранее копии CloudStream автоматически не удаляет.
