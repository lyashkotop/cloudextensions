# UKDevilz: адаптация оригинального NoodleMagazine

Базовый код phisher98 сохранён в предыдущей версии/истории Git; текущая версия доработана по запросу владельца. Название UKDevilz, оригинальная схема поиска и разделы главной сохранены. Снова подключены ReliableProvider и общий кэш Coil, запрос не переводится.

Исправления: обложки из настоящих lazy/src/srcset вместо единственного data-src, заголовки запроса изображения и сохранение обложки после открытия; настоящие теги и длительность из карточки; английские подписи тегов; пустое описание; разбор window.playlist без хрупкого substringBefore(';'); отдельные метки качеств; проверка доступности файлов; сохранение Range/If-Range вместо удаления всех заголовков.

Поиск: исходный /video/$query?p=$page не перенумерован и не заменён другим API; div.item сохраняется. Четыре ответа реального сайта (guy/парень, страницы 1/2) сохранены и разобраны старым и новым провайдером независимо: все 96 URL и порядок совпали. Файлы HTML в репозиторий не добавлены; структурированные результаты search-comparison.json. Это сравнение одинаковых HTTP-ответов, не поддельных карточек. При отдельных повторных живых HTTP-запросах встречались изменения ранжирования/одной карточки на стороне сайта, поэтому идентичность выдачи во времени не заявляется. В этих четырёх ответах адреса обложек были заполнены и до исправлений — реальная отсутствующая lazy-ветка на них не воспроизведена.

Дополнительно через настоящий SDK ReliableProvider.search: 24 карточки, все с адресами обложек, порядок — подмножество исходной последовательности. При другом запросе фильтр может убрать записи по правилам. Открытая карточка сохранила обложку и получила 10 настоящих английских тегов. Плейлист вернул подтверждённый MP4 360p, повторный запрос дал HTTP 206 и ftyp. Отдельно проверено, что интерцептор сохраняет Range/If-Range (детерминированная проверка цепочки). Результаты live.json.

Три проверки самих превью в этой среде завершились IOException при соединении с CDN, хотя адреса обложек присутствовали. Альтернативный видео-CDN не использован как неподтверждённая замена обложек. Серверные/сетевые ошибки не устранены этим разбором HTML: доступность всех изображений и качеств не подтверждена. Android UI и фактическая плавность загрузки фотографий не проверялись. Новые фиктивные теги/фото/качества не создаются.
