# Агрегаторы и пустой поиск — 2026-11-16

Исправлены переходы TubeBDSM/TubeSafari к внешнему источнику. Ошибка HTTP хранит конечный URL: ограниченный повтор 429 и обработчик Cloudflare получают именно его. Повтор учитывает Retry-After; длинное ожидание не заменяется ранним повтором. Cookie/Authorization исходного домена не пересылаются вручную другому домену при повторе. Явный cf-mitigated: challenge распознаётся и при изменённом прокси заголовке Server; используется WebView-обработчик приложения. Успешное прохождение Cloudflare на Android здесь не подтверждено.

HLS определяется по Content-Type и параметру hls=1 даже у адреса .mp4. Поддержаны отложенные iframe, конечные адреса iframe и опубликованная ссылка XHamster из sharingComponent. Преобразование публичных адресов XHamster перенесено из алгоритма его плеера; происхождение и SHA-256 в player-url-source.json. Значения неизвестного формата не выдаются как потоки. Разрешение берётся из источника, максимум 1080p.

AbXXX использует свои API video/videofile/videos_related2 и свой публичный алфавит URL. В проверенной карточке получены название, длительность, 14 меток и 20 рекомендаций. Настоящего описания в ответе нет: поле оставлено пустым. Проверка не синтезирует рекламный текст или теги.

ThisVid при пустом поиске сам показывает Trending Videos. Поиск теперь читает только list_videos_common_videos_list_items, соседние тренды исключены. Реальный запрос guy вернул 12 карточек; zzqvnoresult987654321 — 0 результатов при наличии 12 трендовых карточек на странице. Пустая выдача заканчивает пагинацию. Механизм объединения с переводом сохранён.

## Проверка

- 133 проверки Kotlin общего кода прошли; ThisVid, TubeBDSM и TubeSafari скомпилированы и проверены по DEX.
- NetworkRetryTest.kt проверен на настоящем локальном HTTP-сервере: редирект запрошен один раз, конечный endpoint после 429 повторён один раз; Retry-After: 120 не запускает ранний повтор.
- В live.json — выполнение текущего общего Kotlin-кода с реальными CloudStream SDK и HTTP-запросами. Проверяется только первый фрагмент файла/манифеста; фото и видео не отображались.
- Все 12 проверенных случаев дали поток HTTP 206: Yesvids, MyLust, AbXXX, TheyAreHuge, а также 8 страниц TubeSafari→XVideos/XHamster/Pornhub, включая URL из исходного лога ошибки. Время включает извлечение, варианты качества и проверку потока; это не замер Android UI.
- XGroovy продолжает возвращать 403 Cloudflare. Отдельный XVideos embed из выборки TubeSafari возвращает 404 у самого источника. Исправление парсера не восстанавливает удалённую запись. Открытие всех роликов не подтверждено.

XVideos перенесён как отдельное расширение в Unused и исключён из сборки/индекса. Поддержка встроенных плееров других сайтов сохранена. Ранее установленный XVideos приложение автоматически не удаляет.
