# Импорт CloudstreamAdult

Из предоставленного владельцем `CloudstreamAdult.cs3` версии 1 выделено девять самостоятельных расширений:
CosXPlay, EPorner, Heavy-R, Noodle Magazine, SpankBang, Whoreshub, XRares, xVideos, XNXX.
Они находятся в `English/`, общая реализация — `common/smali/com/lagradost/AdultVideoProvider*`
и `AdultProvidersKt.smali`. Оригинальный объединённый entry point не включён, чтобы не было
повторной регистрации всех сайтов при установке одного расширения. Удали прежний общий
CloudstreamAdult, если устанавливаешь отдельные расширения из этого репозитория.

В `provenance.json` сохранены SHA-256 исходного пакета, его манифест и соответствие классов сайтам.

## Адаптация

- Отдельная регистрация, стабильные ID, английская группа, собственные иконки и автоматические обновления.
- Тип контента исправлен с `Movie` на `NSFW` в списках и карточках.
- Убраны 20 вызовов `SpillingKt.nullOutSpilledVariable`, требующих Kotlin 2.3: заменены на присваивание null,
  как в release-реализации Kotlin. Служебные coroutine-классы сохранены.
- Уже загруженные документы передаются общей обработке метаданных без дополнительных HTTP-запросов.
- Подключены общий выбор названия, описание/точная длительность/теги из полей источника,
  фильтрация карточек и результатов поиска, нормализация дублей.
- Исходный код извлечения вариантов видео сохранён.

## Пределы проверки

Сборка проверяет пакеты и регистрацию, но не подтверждает работу внешних сайтов или Android UI.
У исходного пакета нет реализации главной страницы, рекомендаций и двуязычного поиска с пагинацией.
Импорт не добавляет эти функции автоматически. Подключение общего обработчика также не доказывает,
что селекторы подходят разметке каждого нового сайта: описания, время и теги могут отсутствовать.
Неизвестные значения не выдумываются. Для полного переноса на Kotlin нужны исходники либо отдельная
миграция; предоставленный файл содержит только DEX и манифест.
