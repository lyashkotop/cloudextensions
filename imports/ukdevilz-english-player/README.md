# UKDevilz: английский профиль и плеер

Проверенная ссылка: https://ukdevilz.com/watch/-141286211_456239068

Причина ошибки извлечения: страницу обслуживает JWPlayer с реальным window.playlist.sources; общий обработчик раньше не читал этот формат. Теперь сохраняются объявленные сайтом ссылки и метки качества. Для UKDevilz включена предварительная HTTP-проверка потока; неподтверждённые адреса не выдаются за рабочие. Нестабильный CDN может уменьшить список качеств при конкретном запросе.

В последней проверке настоящего SDK loadLinks вернул MP4 480p, 360p, 240p и запасной прямой файл. Все повторные проверки файлов дали HTTP 206 и сигнатуру ftyp. В отчёте quality — внутреннее числовое поле SDK, четвёртый файл не имеет объявленной метки разрешения на странице. Видео/изображения не просматривались. В более ранних попытках прокси среды периодически блокировал отдельные CDN-соединения, поэтому доступность на любой сети не обещается.

load(): описание пустое, 10 английских тегов после очистки и перевода настоящих подписей сайта. Сам сайт на этой странице отдавал русские теги даже с ui_lang=en и не предоставлял английский словарь тегов.

Реальный поиск «парень»: отдельно получены английская guy и русская парень ветки (по 21 исходной карточке). Объединённая выдача после фильтров — 38 карточек, английская первой, есть дополнительные карточки только из русской ветки, дублей нет. Проверен порядок английских результатов после исключения заблокированных карточек. Это специальное правило UKDevilz; у других источников исходный запрос по-прежнему первый.

100 проверок общего кода прошли, UKDevilz скомпилирован и проверен DEX/entry. live.json и search-order.json — структурированные итоги реальных запросов. Проверка Android UI не проводилась.
