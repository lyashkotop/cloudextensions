# Завершение перехода на Kotlin

Последние 16: HurtSex, Pervertium, PornVideos.rs, PunishBang, Punishworld, SICK-R,
SickJunk, ThisVid, TubeSafari, UKDevilz, SpankBang, Whoreshub, XRares, XNXX, xVideos, YouJizz.
Все 48 модулей репозитория теперь компилируются из Kotlin. Устаревшие Smali/Java-парсеры
удалены из текущей ветки; их история сохранена до `ed12096`.

Пять реализаций адаптированы из Kraptor123/Cs-GizliKeyif. Файлы, исходные хэши и коммит
записаны в `provenance.json`. Остальные 11 — собственные профили общего Kotlin-провайдера;
селекторы и настоящие разделы перечислены в `profiles.json`.

Исправления по результатам живой проверки:

- XRares: настоящий `/search/videos`, корректные параметры следующей страницы; приватные карточки исключены.
- YouJizz: поиск со страницами; корректный разбор `//cdn/...` вместо ошибочного `https:////cdn/...`.
- Whoreshub: в выдачу попадают видео, а не категории/альбомы; настоящие метки из вкладки информации; сохранён KVS-экстрактор.
- xVideos: выбор конкретного раздела вместо 16 последовательных запросов на каждое открытие главной; качество High/Low не выдается за выдуманное разрешение.
- TubeSafari: настоящий параметр query, ссылки `/video?id=…`, JSON API продолжения поиска, 84 настоящих жанра для выбора на главной; метаданные доступного оригинала из объявленного embed-источника.
- UKDevilz: маршрут `/video/<query>` из скрипта сайта, настоящий permalink следующей страницы `?p=…`; проверен GET без CSRF-зависимого POST.
- ThisVid: переход по кнопке следующей страницы с пустым текстом; настоящие категории из информации видео.
- SICK-R, SickJunk: отдельные селекторы метаданных; заголовок WordPress-сайта не принимается за название ролика.

Общий код: Cloudflare-обработчик приложения после 403/503; реальное KVS-декодирование;
защита от ссылок на связанные превью при извлечении потока; кэш настоящих обложек и времени;
очистка рекламных описаний; объединение исходного и переведённого поиска; дедупликация
между страницами поиска и главной. Ошибка одного языкового запроса не скрывает успешный второй.
