# Подписи и выбор качества

Причина «3. UKDevilz 720p 720p» подтверждена кодом GeneratorPlayer.refreshLinks закреплённого CloudStream: приложение отображает link.name плюс Qualities.getStringByInt(link.quality). Новая общая обработка в ReliableProvider оставляет имя пустым для числового разрешения, сохраняя само поле quality. Итоговая подпись после обычного пробела приложения — 720p, 1080p, 4K и т. п. Название источника остаётся в source для внутренних целей.

Преобразование действует на callbacks всех 33 активных провайдеров. Сохраняются разные реальные ссылки, referer, headers, extractorData, audioTracks, тип потока, DRM и составные плейлисты. Unknown не превращается в выдуманные 720p: для обычного файла используется «Оригинал», явно помеченных High/Low — «Высокое»/«Низкое», preview only — «Превью».

Для неизвестного HLS читается мастер-плейлист с исходными заголовками: добавляются только объявленные URI с RESOLUTION, исходная Auto-ссылка сохраняется. Относительные URI разрешаются от конечного адреса ответа. Разрешение не выводится из bitrate. Если мастер объявляет внешние дорожки через EXT-X-MEDIA URI, сохраняется оригинальный master/Auto без потенциальной потери аудио и субтитров. Если источник предоставляет только один файл или не указывает разрешения, дополнительные вымышленные качества не создаются.
